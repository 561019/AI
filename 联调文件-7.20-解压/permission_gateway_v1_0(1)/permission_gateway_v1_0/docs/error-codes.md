# 错误码

| 错误码 | 结果 |
|---|---|
| `PERMISSION_GRANTED` | 允许 |
| `USER_NOT_FOUND` | 拒绝 |
| `PERSON_NOT_FOUND` | 拒绝 |
| `NO_ACTIVE_POSITION` | 拒绝 |
| `ACTION_NOT_GRANTED` | 拒绝 |
| `DATA_LABEL_DENIED` | 拒绝 |
| `DATA_STATE_DENIED` | 拒绝 |
| `PERMISSION_EXPIRED` | 拒绝 |
| `SERVICE_CALL_DENIED` | 拒绝 |
| `INVALID_REQUEST` | 异常并拒绝 |
| `PERMISSION_DB_ERROR` | 异常并拒绝 |
| `PERMISSION_SERVICE_ERROR` | 异常并拒绝 |
| `INTEGRATION_EVENT_NOT_ENABLED` | 预留异步事件入口尚未启用，HTTP 501 |
