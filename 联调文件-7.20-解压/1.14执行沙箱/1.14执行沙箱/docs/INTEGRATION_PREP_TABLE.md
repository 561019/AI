## 推荐首个联调场景

```text
销售/供应链：跨部门同时下单超库存预警
```

原因：

- 贴近汉和真实岗位场景。
- 涉及账号角色、权限、ERP 库存/订单数据、沙箱执行、结果预警、成本审计。
- 不依赖大模型和复杂媒体工具，适合作为 L1 1.14 的第一条端到端联调链路。

## 当前联调前置条件

- 真实账号网关提供 `actor` 到用户/岗位/权限的接口。
- 1.9 提供白名单策略和凭据策略接口。
- 1.10 提供库存、订单、发票、合同等测试适配器。
- 1.12 提供成本上报接口。
- L2 引擎按 `docs/PLATFORM_INTERFACE_SPEC.md` 调用，并确认轮询周期；主动回调待监控提醒引擎通知通道就绪后补充。
