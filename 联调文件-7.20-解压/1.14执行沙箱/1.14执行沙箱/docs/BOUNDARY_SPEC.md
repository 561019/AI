# 边界说明

## 1. 本模块负责

执行沙箱负责：

- 创建执行环境。
- 注入代码或任务。
- 隔离执行。
- 限制资源。
- 管控出站。
- 记录执行留痕。
- 取回结果。
- 销毁执行环境。

## 2. 本模块不负责

| 不负责事项 | 归属模块 |
| --- | --- |
| 判断任务该不该跑 | 1.4 驾驭机制 |
| 最大步数、死循环检测 | 1.4 驾驭机制 |
| 真人拍板 | 1.11 人机协同 / 1.4 驾驭机制 |
| 用户、岗位、权限来源 | 1.8 账号网关 |
| 敏感数据规则、出站策略、审计归口 | 1.9 安全合规 |
| ERP/OA/数据库怎么连接 | 1.10 设备与系统接口 |
| 大模型调用 | 1.5 大模型调度 |
| CPU/内存/时长成本记账 | 1.12 成本管控 |

## 3. 当前 mock 边界

为了验证可行性，当前项目用 mock 服务模拟外部模块：

- `MockAccountGateway`
- `MockSecurityCompliance`
- `MockERP`
- `MockOA`
- `MockCostControl`

mock 只能证明链路可行，不代表真实生产联调完成。
