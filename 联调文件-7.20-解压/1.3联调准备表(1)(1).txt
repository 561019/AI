模块名称：L1-1.3 进化机制
负责人：豆贵毅
一、我提供给其他模块的能力：
1. 进化候选生成：接收经验记忆、技能沉淀、提示词打磨三条路径的进化信号，生成可追踪、可比较、可回退的候选版本；不直接生效。
2. 风险关卡与真人确认：根据使用范围、风险标签、证据完整性和目标动作判断低风险自动生效、需本人确认、需人工审批或阻断，并校验操作者身份和权限。
3. 版本治理：支持候选查询、本人确认、人工审批、正式发布、每日沉淀逐卡片决策、审计留痕和版本回退。

二、我提供的接口：
接口1：进化分析与候选生成（当前联调接口）
- 路径：POST /api/l1/evolution/analysis
- 方法：POST
- 输入：tenantId、userId、scenarioId、messages、attachments、currentVersion（可选）；请求头建议携带 Authorization、X-Request-Id、X-Actor-Id、X-Tenant-Id。
- 输出：requestId、analysis.provider、analysis.skill、analysis.canProceed、evidence、missingEvidence、proposedVersionId；输出为 Skill 草案或候选版本，不直接发布。
- 错误情况：400 请求格式错误；401 身份无效；422 证据不足；502 DeepSeek 调用或上游分析失败；500 1.3 内部错误。当前服务支持 DEEPSEEK_TIMEOUT_MS 超时保护。

接口2：候选版本治理（正式契约，当前由本地治理服务 mock）
- 路径：POST /api/l1/evolution/candidates、GET /api/l1/evolution/candidates/{candidateId}、POST /api/l1/evolution/candidates/{candidateId}/risk-check、POST /api/l1/evolution/candidates/{candidateId}/confirmations、POST /api/l1/evolution/candidates/{candidateId}/approvals、POST /api/l1/evolution/candidates/{candidateId}/publish、POST /api/l1/evolution/assets/{assetId}/rollback
- 方法：POST / GET
- 输入：候选内容、evolutionPath、scenarioId、subjectUserId、scope、sourceRefs、evidence、riskTags、确认动作、审批决定、回退原因；写操作必须携带 Idempotency-Key。
- 输出：candidateId、status、riskLevel、decision、requiredConfirmation、requiredApproverRoles、requestId、auditId、可执行动作和错误码。
- 错误情况：400 INVALID_REQUEST；401 ACTOR_UNAUTHENTICATED；403 ACTOR_FORBIDDEN；404 CANDIDATE_NOT_FOUND；409 IDEMPOTENCY_CONFLICT / CONFIRMATION_STALE；422 EVIDENCE_INSUFFICIENT；423 RISK_BLOCKED；424 TARGET_MODULE_UNAVAILABLE；500 EVOLUTION_SERVICE_ERROR。

三、我需要调用哪些模块：
1. 需要调用模块：L4 用户与Agent / 业务引擎层
   - 调用目的：提交聊天记录、业务反馈和附件证据，触发1.3生成进化候选。
   - 需要对方提供什么接口：用户身份、租户、Agent和场景上下文；消息与附件提交接口；候选结果展示及用户选择回传接口。
   - 当前是否已 mock：是。当前页面已模拟L4提交、L2分发、1.3分析和Agent查询链路。
2. 需要调用模块：AI API / DeepSeek适配层
   - 调用目的：根据真实业务输入生成结构化Skill草案或候选版本。
   - 需要对方提供什么接口：POST /api/l1/evolution/analysis；返回严格结构化JSON，并支持超时、错误码和requestId。
   - 当前是否已 mock：否。DeepSeek真实调用已接入；无API密钥或调用失败时页面保留错误提示，不直接发布。
3. 需要调用模块：数字资产引擎、记忆管理、上下文与提示词管理、数据模块
   - 调用目的：在风险关卡通过后分别登记或写入对应进化成果。
   - 需要对方提供什么接口：候选接收、资产登记、内容写入、版本查询和回退指针更新接口；不得直连对方数据库。
   - 当前是否已 mock：是。当前使用本地治理服务和内存存储模拟登记、发布、审计和回退。
4. 需要调用模块：统一身份与权限、审计服务
   - 调用目的：实时校验本人确认、业务负责人审批、租户范围和操作权限，并记录全链路审计。
   - 需要对方提供什么接口：当前操作者身份、角色、租户、资源范围校验接口；审计事件写入和查询接口。
   - 当前是否已 mock：是。当前治理测试使用模拟身份、角色和审计存储。

四、当前 mock 的内容：
1. 10个业务场景、用户、聊天记录、附件证据、Agent查询和相似能力提示。
2. L4提交 → L2分发 → 1.3内部AI分析 → 风险关卡 → 用户选择 → 1.7版本治理 → L2/L4返回的完整页面链路。
3. 三条轻量进化路径的候选生成、证据状态和缺失证据提示。
4. 低风险、中风险、高风险判断；本人确认、业务负责人审批、证据不足阻断和越权拒绝。
5. 候选幂等、发布、重复发布拦截、审计记录和版本回退。
6. 每日沉淀卡片的KEEP、EDIT_AND_KEEP、SNOOZE、REJECT决策模型。
