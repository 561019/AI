# 接口与字段总说明

编制日期：2026-07-17

本文汇总交付包内四个本地模块当前暴露的接口、请求字段、关键返回字段和 callback 字段。  
本文件用于联调对字段，不替代正式平台接口规范。

## 一、模块与端口

| 模块 | 默认地址 | 说明 |
|---|---|---|
| 内容产出引擎 v0.2 | `http://127.0.0.1:8011` | 承接文字类子任务，生成文字初稿/文字成果引用 |
| 多媒体生成引擎 v1.1 | `http://127.0.0.1:8013` | 承接图片、视频、音频类子任务，生成方案、提示词、素材引用 |
| 本地知识库 v0.1 | `http://127.0.0.1:8012` | 本地模拟 L1.13 知识库取材服务 |
| 本地流程执行引擎 | `http://127.0.0.1:8020` | 本地模拟流程派发、callback 接收、真人确认 |

说明：正式架构中，知识库和大模型都应走平台/基础模块层接口。本地版本中的 `KB_BASE` 和 LLM 直连只是为了验证联调逻辑。

## 二、内容产出引擎接口

### 1. 接收内容产出子任务

```text
POST /api/content-production/subtasks
```

用途：流程执行引擎向内容产出引擎派发文字类子任务。

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `trace_id` | string | 否 | 跨模块追踪编号 |
| `message_id` | string | 否 | 消息编号 |
| `parent_message_id` | string | 否 | 上游消息编号 |
| `workflow_instance_id` | string | 否 | 流程实例编号 |
| `node_id` | string | 否 | 流程节点编号 |
| `task_id` | string | 否 | 上游指定子任务编号；不传则本地生成 |
| `idempotency_key` | string | 否 | 幂等键 |
| `caller` | object | 否 | 调用方信息，可放 `service_code`、`service_name`、callback 字段 |
| `actor` | object | 否 | 当前真人信息，常用 `person_id` |
| `capability` | object | 否 | 能力信息，常用 `capability_id`、`schema_version` |
| `request_type` | string | 否 | 默认 `execute` |
| `input` | object | 否 | 任务输入，常用 `requirement`、`content_type`、`source_material_refs` |
| `expected_return` | object | 否 | 期望返回，可放 callback 字段、输出要求 |
| `policy` | object | 否 | 策略字段，可放 callback 字段、review 策略 |
| `callback_url` | string | 否 | 简化 callback 地址 |
| `callback_envelope_url` | string | 否 | 平台信封 callback 地址 |
| `callback_protocol` | string | 否 | `simple` / `platform_v1` |
| `callback_timeout_seconds` | integer | 否 | callback 超时秒数，默认 8 |
| `callback_headers` | object | 否 | callback 请求头 |
| `parent_task_id` | string | 否 | 上游任务编号 |
| `caller_engine` | string | 否 | 调用方名称，默认“流程执行引擎” |
| `operator_real_person_id` | string | 否 | 当前真人编号 |
| `requested_service` | string | 否 | 请求服务名称 |
| `content_type` | string | 否 | 内容类型 |
| `input_brief` | string | 否 | 已确认任务描述 |
| `source_material_refs` | array | 否 | 资料、知识库、爆款样板等引用 |
| `template_id` | string | 否 | 模板编号 |
| `expected_output` | string | 否 | 期望输出说明 |
| `review_policy` | string | 否 | 默认 `pending_human_confirmation` |
| `security_context` | object | 否 | 权限/安全上下文 |
| `scenario_id` | string | 否 | 本地演示场景编号 |
| `artifact_refs` | array | 否 | 输入产物引用 |
| `knowledge_refs` | array | 否 | 知识资料引用 |
| `context_refs` | array | 否 | 上下文引用 |
| `decision_id` | string | 否 | 权限判定编号 |
| `audit_ref` | string | 否 | 审计引用 |

关键返回字段：

| 字段 | 说明 |
|---|---|
| `ok` | 是否接收成功 |
| `content_task_id` / `task_id` | 内容产出任务编号 |
| `trace_id` | 追踪编号 |
| `status` | `accepted`、`running`、`completed`、`waiting_human_confirmation`、`failed` 等 |
| `accepted_receipt` | 接收回执 |
| `task_adapter_result` | 任务归一、边界校验、缺项提示 |
| `callback` | callback 配置摘要 |
| `result_refs` | 文字成果引用 |
| `permission_result` | 本地权限判定结果 |
| `audit_ref` | 审计引用 |


说明：正式路由应由流程执行引擎或平台接口层根据能力登记表固化，多媒体只做边界校验和承办。

### 4. 多媒体大模型调度接口位

多媒体请求中可传 `model_dispatch_interface_slot`，也可放在 `input.model_dispatch_interface_slot`。本字段用于正式接入 1.5 大模型调度模块，本地版仍可通过 LiteLLM/Kimi 直连或 Mock 方案验证流程。

建议字段：

| 字段 | 说明 |
|---|---|
| `target_service` | 目标服务，建议为 `l1.model_dispatch` |
| `target_module` | 目标模块，建议为 `1.5 大模型调度` |
| `expected_path` | 建议路径，例如 `POST /api/model-dispatch/chat-completions` |
| `required_action` | 建议动作，例如 `model.chat_completion` |
| `request_schema_version` | 请求 schema 版本 |
| `response_schema_version` | 返回 schema 版本 |
| `timeout_seconds` | 调用超时时间 |

结果中会返回 `model_dispatch_usage`，说明当前是否启用、正式目标接口、schema 版本和本地替代模式。

`POST /api/config` 请求字段：

| 字段 | 类型 | 必填 | 说明 |

| `kb_base` | string | 否 | 知识库服务地址，默认本地 `http://127.0.0.1:8012` |
| `llm_protocol` | string | 否 | 当前支持 `openai_compatible` |

| `kimi_model` | string | 否 | 模型名 |
| `litellm_key` | string | 否 | 模型密钥 |

### 6. 多媒体本地调试接口

## 四、本地知识库接口

说明：本模块只用于模拟 L1.13 知识库取材。正式联调时，应替换为平台或基础模块层提供的知识库检索/取材接口。

### 1. 按任务类型取素材

```text
POST /api/kb/task-materials
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `actor_id` | string | 是 | 当前操作真人 |
| `task_type` | string | 是 | 任务类型，如 `multimedia_poster`、`hot_case_reuse` |
| `query` | string | 否 | 检索问题或任务描述 |

关键返回字段：

| 字段 | 说明 |
|---|---|
| `actor_id` | 当前真人 |
| `task_type` | 任务类型 |
| `query` | 检索内容 |
| `readiness` | 资料准备状态 |
| `materials` | 可用素材、模板、风格参考、爆款样板等 |
| `templates` | 模板结果 |
| `references` | 引用来源 |

### 2. 普通知识库检索

```text
POST /api/kb/search
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |

## 五、本地流程执行引擎接口

### 1. 启动流程

```text
POST /api/flow/start
```

请求字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `actor_id` | string | 否 | 当前责任真人，默认 `U001` |
| `source_module` | string | 否 | 上游来源模块，默认 `local_l4_demo` |
| `workflow_type` | string | 否 | 流程类型，默认 `media_only` |
| `requirement` | string | 是 | 已确认的 L4 原始需求或结构化任务描述 |
| `task_type` | string | 否 | 传给多媒体/知识库的取材任务类型，默认 `multimedia_poster` |
| `capability_id` | string | 否 | 多媒体能力接口位，默认 `text_to_image` |
| `output_type` | string | 否 | 多媒体输出类型，默认 `poster_plan` |
| `top_k` | integer | 否 | 知识库取材数量，1-20，默认 8 |
| `use_llm` | boolean | 否 | 是否要求多媒体真实调用 LLM，默认 true |
| `review_policy` | string | 否 | `always` / `none`，本地默认 `always` |
| `batch_count` | integer | 否 | 批量爆款数量，1-5，默认 3 |
| `hot_case_refs` | array | 否 | 爆款案例引用 |
| `skill_refs` | array | 否 | 爆款模式/制作标准技能引用 |
| `expert_agent_ref` | string | 否 | 专家分身引用 |
| `project_id` | string | 否 | 项目/会话归属标识 |
| `share_scope` | string | 否 | 技能推广范围 |
| `idempotency_key` | string | 否 | 幂等键 |

`workflow_type` 当前可用值：

```text
media_only
content_then_media
hot_case_batch
hot_case_sample_then_batch
expert_agent_plan
skill_promotion_authorization
```

关键返回字段：

| 字段 | 说明 |
|---|---|
| `instance_id` | 流程实例编号 |
| `trace_id` | 追踪编号 |
| `status` | 流程状态 |
| `nodes` | 节点列表 |
| `events` | 流程事件 |
| `exit_type` | 出口类型 |
| `content_task_id` | 内容产出任务编号，如有 |
| `multimedia_task_id` | 多媒体任务编号，如有 |

| `workflow_instance_id` | string | 否 | 流程实例编号 |
| `node_id` | string | 否 | 节点编号 |
| `task_id` | string | 是 | 子任务编号 |

## 六、callback 字段汇总

内容产出和多媒体子任务接口均支持 callback。callback 用于把子任务执行状态和结果回传给流程执行引擎，不负责能力路由、知识库取材或真人确认组织。

### 1. 请求侧 callback 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `callback_url` | string | 简化回调地址，通常为本地 `POST /api/flow/callback` |
| `callback_envelope_url` | string | 平台信封回调地址，正式联调可使用 |
| `callback_protocol` | string | `simple` / `platform_v1`；传 `callback_envelope_url` 时默认 `platform_v1` |
| `callback_timeout_seconds` | integer | 回调请求超时时间，默认 8 秒 |
| `callback_headers` | object | 回调请求附加请求头 |

这些字段可放在请求顶层，也可放在 `expected_return`、`policy` 或 `caller` 中；顶层字段优先。

### 4. callback 状态口径

| 状态 | 含义 |
|---|---|
| `in_progress` | 子任务已接收并开始后台执行 |
| `completed` | 子任务完成，可由流程执行引擎推进后续节点 |
| `waiting_human` | 子任务已生成结果，但需要真人确认后才能交付 |
| `failed` | 子任务失败，流程执行引擎应进入失败依赖或无法处理出口 |

## 七、常见错误码

| 错误码 | 位置 | 含义 |
|---|---|---|
| `CP_001_MISSING_FIELD` | 内容产出 | 缺少任务描述或必要字段 |
| `CP_003_PERMISSION_DENIED` | 内容产出 | 权限不足 |
| `CP_400_UNKNOWN_OPERATOR` | 内容产出 | 无法匹配当前真人 |
| `CP_404_TASK_NOT_FOUND` | 内容产出 | 任务不存在 |
| `CP_400_BAD_REVIEW_STATE` | 内容产出 | 当前状态不允许确认 |
| `KB_400_UNKNOWN_ACTOR` | 知识库 | 未知真人/演示用户 |
| `KB_403_PERMISSION_DENIED` | 知识库 | 知识库资料权限不足 |
| `KB_404_NOT_FOUND` | 知识库 | 资料不存在 |
| `KB_404_TASK_PROFILE` | 知识库 | 任务类型不存在 |
| `KB_409_DUPLICATE_ID` | 知识库 | 资料 ID 重复 |

多媒体接口在字段校验、知识库连接、LLM 调用失败时，通常会以 HTTP 422 或 502 返回 `detail`，其中包含 `status=failed`、`error` 和事件记录。
