# 基础模块层接口

唯一的 L1 外部入口。只接受已登记 L2 服务的签名请求；每次转交先机制性直达权限模块，未获允许绝不调用目标服务。当前版本已提供服务登记、签名准入、转交重放防护和判权链路；目标 L1 服务处理器将按服务逐项迁入。

本地运行：复制 `.env.example` 后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8002`。Docker 联调使用 `scripts/up.ps1 -Detach`；权限服务、账号网关和层接口的机制密钥/目标服务密钥必须分别一致，且身份上下文校验密钥在当前 HMAC 实现中与账号网关 JWT 签名密钥一致。
