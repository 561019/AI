# 联调检查表

- [ ] Docker Compose 构建并启动账号网关 `:8080`、权限模块 `:8001`、L1 层接口 `:8002`。
- [ ] 三个 `/health` 端点均返回 HTTP `200`。
- [ ] 使用实名账号登录，确认 `user_id = actor_id = person_id`。
- [ ] 账号网关签发的 `IdentityContext` 包含当前租户、岗位和汇报范围。
- [ ] L2 使用登记服务身份和 HMAC 调用 `POST :8002/api/layer/dispatch`。
- [ ] 已登记服务和岗位标准授权时，层接口返回 `success` 与 `permission_decision_id`。
- [ ] 无授权、跨租户、过期授权、冻结数据或非法动作时，层接口拒绝且目标服务未执行。
- [ ] 按 `trace_id` 查询 `GET :8001/api/permission/audits`，核对 `request_id`、`transfer_id`、责任真人和 `decision_id`。
- [ ] 岗位标准、转授、数据登记和资源发布只调用权限模块控制面，不写账号网关权限表。
- [ ] `/api/ui-permissions`、审批、资源、转授等退役网关接口返回 `410 permission_capability_moved`。
- [ ] 响应、日志、ZIP 中不含真实密码、JWT、工具凭证明文、数据库或运行日志。
