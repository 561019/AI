# 规则计算引擎交付说明

更新日期：2026-07-20

本目录可作为独立交付包发送，不依赖工作区内其他文件夹完成核心测试和本地验证。

## 目录说明

- `项目现状交接说明.md`：引擎定位、已实现能力、接口、边界和待联调事项。
- `流程执行引擎联调约定.md`：两阶段 `rule.evaluate` 的报文衔接、状态映射和当前流程侧待实现项。
- `rule_calc_engine_core/`：规则计算引擎后端、测试、脚本和本地测试页面。
- `test_services/digital_asset_simulator/`：路径三候选 Skill 资产回传的可选本地模拟服务。
- `打包交付资料.ps1`：生成清理后的交付压缩包，默认排除缓存、本地数据库和 `.env`。

## 快速验证

需要 Python 3.11 或 3.12。进入 `rule_calc_engine_core` 后执行：

```powershell
python -m pip install -r requirements.txt
```

双击 `检查核心链路.cmd`，或执行：

```powershell
python -m unittest discover -s tests
python -m scripts.smoke_two_stage
```

两阶段烟测验证：首次计算评估返回受限查询需求；补齐规则参数和业务数据引用后，进入确定性计算并返回受治理的真人确认结果。

如需查看本地测试页面，可双击 `启动测试台.cmd`，保持终端窗口开启，然后访问：

```text
http://127.0.0.1:8010/test-console
```

## 路径三可选验证

`test_services/digital_asset_simulator` 是候选 Skill 资产服务的本地模拟，不是正式数字资产引擎或 L1.3 进化机制。默认 mock 模式下不需要模型密钥。

规则计算引擎自身的路径三合同可直接通过 `启动路径三联调.cmd` 或 `python -m scripts.smoke_path_three` 验证。它覆盖：用户授权、候选 Skill 创建申请、`candidate_request_id` 绑定核对、候选实现引用恢复、受控沙箱试算和真人复核等待。

## 交付边界

- 本包不包含正式平台服务、正式大模型调度、正式数据存储、正式账号权限安全、真实外部系统或生产级 L1.14 Agent 执行沙箱。
- 本包内的 SQLite、固定测试数据和本地适配器只用于验证接口合同和核心逻辑。
- 单独运行测试时，依赖外部流程执行引擎参考框架的测试会自动跳过，不影响本包核心测试。
- 不要把本地模拟结果当作企业正式结算、写回或规则发布结果。

## 打包

在本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\打包交付资料.ps1
```

脚本会在当前目录的上一级生成 `rule_calculation_engine_delivery_日期.zip`，并排除 `__pycache__`、`.pyc`、本地 `rule_engine.db`、`.env` 和路径三模拟服务运行时生成的 `artifacts`。
