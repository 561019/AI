# 数字资产引擎测试服务

该服务只用于验证规则计算引擎路径三的跨引擎合同。它模拟数字资产引擎接收临时分析规格，并返回候选 Python 资产引用；其中可选 DeepSeek 调用代替尚未接入的 L1.3 进化机制生成环节。规则计算引擎不会读取 `DEEPSEEK_API_KEY`，也不会直接调用大模型。

## 运行方式

1. 默认保持 `.env` 中 `DIGITAL_ASSET_PROVIDER=mock`，可在无 API Key 的情况下完成联调。
2. 需要真实生成时，将它改为 `deepseek`，并只在本目录 `.env` 的 `DEEPSEEK_API_KEY` 后填写密钥。
3. 双击 `启动数字资产测试服务.cmd`，服务地址为 `http://127.0.0.1:8020`。
4. 再使用规则计算引擎目录中的 `启动路径三联调.cmd` 启动规则计算引擎。

生成物保存在本目录 `artifacts/`，属于候选代码资产，不是正式规则或正式计算能力。候选代码经过基础语法限制，但该测试服务和本地受限子进程都不等同于生产级 L1.14 Agent 执行沙箱。
