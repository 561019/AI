# 数字资产引擎联调必读

版本：v0.2｜日期：2026-07-19｜正式联调入口：`POST /api/flow/tasks`

## 1. 本模块负责什么

数字资产引擎只管理 **Agent、Skill、Knowledge Base** 三类资产的登记册：创建、修改、草稿删除、标签检索、版本和技术证据登记。

- 不保存业务数据；业务数据查询交数据操作引擎。
- 不做文档解析；知识源的解析、切分、索引交文档表格解析引擎，经流程执行引擎回调本模块登记状态。
- 不执行 Skill、不过问具体业务计算；运行由承办业务引擎和 L1 固定工具完成。
- 标签只用于说明和检索，**绝不作为权限字段**。
- 每个动作以 `actor.person_id` 代表当前真人；权限判断由账号网关/安全合规等外部模块实时完成。本项目中的 L1 适配器仅是本地 Mock。

## 2. 对外正式接口

其他 L2 引擎、流程执行引擎只能调用：

```text
POST /api/flow/tasks
```

请求必须来自 `L2 / l2.workflow_execution`，目标必须是 `L2 / l2.digital_asset`，通道必须是 `l2_internal`。服务端会校验当前真人、信封完整性、服务目录和幂等键；直接传资产编号不构成越权访问入口。

控制台使用的 `/api/assets/*`、`/api/console/*` 为本地页面兼容接口，**不能作为跨模块联调契约**。

  "target": {"layer": "L2", "service_code": "l2.digital_asset"},
  "channel": "l2_internal",
  "route_type": "task.dispatch",
  "action": "asset.query",
  "capability_id": "CAP.DIGITAL_ASSET.ASSET_QUERY",

  "registry_version": "v1",
  "actor": {"person_id": "tester_a", "tenant_id": "tenant_demo"},
  "context": {
    "workflow_instance_id": "wf_001",
    "node_id": "node_001",
    "task_id": "task_001",

| service_code | action | 结果 |

| `l2.digital_asset.asset.create` | `asset.create` | 新建 Agent / Skill / Knowledge Base 登记草稿 |
| `l2.digital_asset.asset.query` | `asset.query` | 按 ID、类型、状态、关键字、标签检索登记册 |
| `l2.digital_asset.asset.update` | `asset.update` | 更新可变字段，生成版本与留痕 |

| `l2.digital_asset.skill.model_evaluation.register` | `skill.model_evaluation.register` | 登记主力/备用模型评测证据 |

## 5. 标准回执

`/api/flow/tasks` 只返回三种 `reply_type`：

- `success`：同步动作完成，HTTP 201；
- `accepted`：长任务已受理，HTTP 202；
- `failed`：协议或业务动作失败，HTTP 4xx。

知识源登记是异步动作，返回 `accepted`，其中包含：

```json
{
  "callback_expected": true,
  "callback_action": "knowledge_source.result.register",
  "correlation": {
    "trace_id": "trace_001",
    "parent_task_id": "task_001",
    "source_id": "src_xxx",
    "artifact_ref": "minio://bucket/object-key"
  }
}
```

文档解析引擎的回执必须沿用同一 `trace_id`，并带 `parent_task_id` 和完全一致的 `artifact_ref`；否则服务端拒绝登记。Word/PDF 原件、切片正文和向量正文不写入资产登记册。

## 6. 已验证与未替换的依赖

已通过本地回归测试：正式信封字段校验、幂等重放、资产登记、Skill 研发/实现/评测生命周期、知识源异步回调关联、前端语法检查。

当前仍是联调准备包，不是生产交付：L1.7 数据、L1.8 账号、L1.9 合规、L1.13 知识库、L1.3 进化机制和文档表格解析引擎仍以 Mock 适配器表示。联调时必须由各模块的真实接口替换这些 Mock，不能宣称已经完成真实跨模块集成。

## 7. 启动与验证

```powershell
python server.py
powershell -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

Python 代码仅使用标准库。验证脚本会运行 Python 回归测试与 `node --check`；若本机没有 Node，可先单独运行 Python 测试。
