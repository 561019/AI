## 必备运维接口

```http
GET /health
GET /ready
GET /api/v1/capabilities
POST /api/v1/instructions
GET /api/v1/tasks/{task_id}
POST /api/v1/callbacks
```

不需要的接口必须明确标记“不适用”，不能留空。

## 边界声明

- 不直接读取其他模块数据库。
- 不直接调用同层模块。
- 不接受未经过层接口的跨层请求。
- 不自行保存权限规则副本。
- 不把大模型用于确定性数字计算。
- 不在日志中记录密钥或完整敏感正文。
